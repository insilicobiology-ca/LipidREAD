# Computational Lipidomics (CompLi)

CompLi is a database and software solution that provides a knowledge base for lipid reactions. 
CompLi links manually curated lipid reactions, the enzymes involved and the evidence for each reaction and includes information about ~800,000 lipid specie, and 3,000 enzymes across different organisms.
